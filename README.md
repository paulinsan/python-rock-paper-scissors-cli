# 🎮 Python Rock Paper Scissors

Projeto desenvolvido em **Python** com o objetivo de criar um jogo de **Pedra, Papel e Tesoura** executado pelo terminal.

> 🚧 **Status: Em desenvolvimento**

O projeto está sendo desenvolvido gradualmente, recebendo novas funcionalidades conforme novos conceitos de programação são estudados.

## 📌 Sobre o projeto

O jogador escolhe entre Pedra, Papel ou Tesoura, enquanto o computador realiza uma escolha aleatória.

O projeto começou com uma implementação simples e está sendo evoluído para praticar conceitos importantes de programação em Python.

## 🛠️ Tecnologias utilizadas

* 🐍 Python
* 🎲 Biblioteca `random`

### Biblioteca utilizada

```python
import random
```
